# Flip Fall Flat

Clavadismo ragdoll en el navegador: Flip Diving + Human Fall Flat.

## Contenido

### 6 escenarios
Costa Escondida (gratis), Muelle del Pez (350), Selva Saltadora (1100), Azoteas (2400), Foso del Castillo (4200), Banquisa (6800).

Cada uno trae 3 trampolines distintos (madera, grúa, liana, tejado, almena, hielo, etc.).

### 9 trucos
Mortal, Invertido, Gainer, Carpa, Layout, Twist, Doble mortal, Bomba y Superman.

## Controles
Espacio o clic para saltar. A/D girar. S o F encoger. W estirar. Q/E cambiar truco. 1-6 cambiar escenario. Esc menu. R repetir.

Abre index.html en Chrome, Edge o Firefox.
